# 🔦 הקומה האבודה – גרסה 10

## העלאה ל-GitHub
1. פותחים את קובץ ה-ZIP במחשב (לחיצה ימנית, ואז "חלץ הכל").
2. ב-repository **lost-floor** לוחצים **Add file**, ואז **Upload files**.
3. גוררים **את כל התוכן** של התיקייה (index.html, manifest.webmanifest, sw.js, ואת התיקיות icons ו-branding) ולוחצים **Commit changes**.
4. מחכים 1–2 דקות ופותחים: https://dexx-9ii.github.io/lost-floor/ (עם Ctrl+Shift+R).

## התקנה כאפליקציה (עם אייקון)
- **אנדרואיד / כרום:** בתפריט ⋮ בוחרים "התקנת אפליקציה", או לוחצים על **📲 התקנה** בהגדרות המשחק.
- **אייפון / אייפד:** פותחים ב-Safari, לוחצים על כפתור השיתוף ⬆️, ואז "הוספה למסך הבית".
- **מחשב (Chrome / Edge):** לוחצים על אייקון ההתקנה בשורת הכתובת.
אחרי ההתקנה המשחק נפתח במסך מלא עם האייקון שלו, ומשחק הסולו עובד גם בלי אינטרנט.

## קבצים
| קובץ | תפקיד |
|---|---|
| index.html | המשחק |
| manifest.webmanifest | שם, צבעים ואייקונים להתקנה |
| sw.js | עבודה בלי אינטרנט, ותמיד הגרסה האחרונה כשיש רשת |
| icons/ | אייקונים לכל המכשירים, כולל icon.ico (Windows) ו-icon.icns (Mac) לקובץ הרצה בעתיד |
| branding/ | הלוגו המלא, האייקון ב-1024 פיקסלים, וסקריפט פייטון שמייצר את כל האייקונים |
